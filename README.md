# 単管パイプ屋根 設計ツール

単管パイプ（φ48.6）で庭の屋根・パーゴラ・簡易車庫などを作るときの、ブラウザで動く簡単な設計ツールです。

寸法を入れると次のものが出ます。

- 3Dで回して見られる骨組み（柱・桁・垂木・母屋・筋交い・火打ち・胴つなぎ）
- 部材リスト（必要な長さと、使う単管の定尺）
- 購入リスト（単管の本数、直交クランプ・自在クランプ、固定ベース、アンカー、波板、フックなど）
- 概算の材料費（単価は画面で変えられます）
- 勾配・柱の間隔・筋交い・建築確認などの注意

## 使い方

`index.html` をブラウザで開くだけです（three.js は CDN から読み込みます）。
GitHub Pages を有効にすれば、そのURLでスマホからも使えます。

- 屋根の形：片流れ／切妻
- 基礎の種類：コンクリートの土間に固定／ピンコロ（束石）に載せる／穴を掘ってコンクリートで固める／地面に直接打ち込む（根入れの深さ・穴の直径も設定可。材料と注意が基礎に合わせて変わります）
- 用語や入力欄の横の「？」にカーソルを合わせる（スマホはタップ）と、初めての人向けの説明が出ます
- 柱の本数（間口方向・奥行き方向）、垂木の本数
- 軒の出・けらばの出・母屋の間隔
- 筋交い（面ごとに、入れるかどうか・片筋交い／たすき・下端と上端の高さを設定）。下端・上端の高さを面ごとに変えられるので、柱の途中から出すこともできます
- 胴つなぎ（前・後・左・右の面ごとに高さを変えられます）
- 火打ち（上の四隅）
- **3面図**：平面図・正面図・右側面図を寸法（mm）付きで表示。SVGで保存、A3横で印刷できます
- **設計の保存と比較**：名前を付けて複数保存し、形・寸法・本数・クランプ数・材料費・注意の数を表で並べて比べられます（保存はブラウザの中）
- **JSONの書き出し・読み込み**：今の設計／保存した全部をJSONファイルにでき、別の端末で読み込めます
- 「この設計のURLをコピー」で設計をURLにして共有できます
- 購入リストはCSVで保存できます

### JSONの形式

```json
{
  "app": "tankan-designer",
  "version": 1,
  "designs": [
    { "name": "今の屋根と同じ", "savedAt": "2026-11-18T00:00:00.000Z", "params": { "W": 3, "D": 3, "roofType": "mono", "H1": 3, "H2": 2.6 } }
  ]
}
```

`params` に書いていない項目は初期値になります。

## 計算の前提

- 6mを超える部材はジョイントでつなぐ前提で分割します
- クランプの数は、部材が交わる点を1か所1個で数えています
- 波板は働き幅58cm、長さは6〜12尺から選びます
- 単価は2026年時点のホームセンター価格をもとにした目安です

**強度計算はしていません。** 積雪や強風のある地域では、柱・垂木・筋交いを増やしてください。不安な場合は専門家に相談してください。

## ファイル

- `index.html` — 画面と3D表示
- `tankan-core.js` — 部材・クランプ・費用の計算ロジック
- `drawing.js` — 3面図（SVG）を描く
- `glossary.js` — 「？」で出す用語の説明
